# 🔁 채팅 이름 일괄 치환 — BETA 0.2.2

[Stay 설치·업데이트](https://raw.githubusercontent.com/shipidle/crack-stay-scripts/beta/Crack_Chat_Name_Replacer.user.js)

## 목적

현재 열려 있는 크랙 채팅방의 **시류 → 유우** 같은 이름을 전체 대화 기록에서 치환합니다. 화면 표시뿐 아니라 **서버 메시지 실제 수정**을 수동으로 실행할 수 있습니다. 요약 메모리와 사용자 노트는 대화 본문과 별도 저장되므로 자동으로 수정하지 않습니다.

## 기능

- **현재 방별 찾기/바꾸기:** 기본 시류 → 유우. 다른 채팅방의 설정과 분리.
- **화면 치환:** 로드된 대화의 글자만 변경. 서버 수정과 별개로 언제든 끌 수 있음.
- **전체 기록 검색:** 크랙 메시지 읽기 API를 페이지별로 마지막까지 조회하여 발견 횟수와 전후 미리보기 표시.
- **원본 백업 JSON / 치환본 JSON:** 메시지 ID·역할·본문 등 주요 필드를 파일로 다운로드. 다운로드 요청만으로 실제 파일 저장을 보장하지 않으므로 파일 앱에서 확인해야 함.
- **서버 1건 시험 수정:** 최근 일치 메시지 하나를 PATCH 요청으로 수정한 후 같은 메시지의 서버 GET 결과와 전체 대화 ID·순서를 검사. **이 버튼은 실제 메시지 한 개를 변경**함.
- **전체 서버 원문 수정:** 시험 통과 후 하나씩 GET → 원문 비교 → PATCH → GET. 이미 수정된 메시지는 건너뜀. 매 10건, 완료 시 전체 기록이 보존되어 있는지 검사하고 완료 시 잔존 이름도 검사.
- **중단:** 진행 중이던 요청까지 취소될 것이라는 보장은 없지만 다음 대상의 처리를 막음. 중단한 경우 재조회한 뒤 재실행 가능.
- **원본 백업으로 복구:** 원본 JSON 선택 시 서버 메시지가 백업 원문/치환본과 일치할 때만 원문으로 복구. 중간에 중단되면 같은 파일로 재개 가능.
- **요약 메모리 이름 검사:** 장기/단기/관계/목표 항목에서 해당 이름의 발견 건수를 조회. **이 기능은 요약 내용을 수정하지 않음.**

## 권장 순서

1. 크랙 채팅방에서 생성 중인 응답이 없는지 확인하고 다른 기기의 동일 채팅방을 닫음.
2. 🔁 메뉴를 열고 전체 기록 검색 → 발견 횟수·예시 검토.
3. 원본 백업 JSON을 눌러 실제로 파일이 저장되었는지 확인.
4. 서버 1건 시험 수정. 이때부터 실제 서버 데이터가 바뀜.
5. 시험 성공 확인 후 전체 서버 원문 수정. 도중에는 새 채팅을 보내지 않음.
6. 완료 후 사이트 새로고침, 전체 기록 다시 검색해 이름 잔존 여부 점검.
7. 요약 메모리 이름 검사. 남은 항목은 크랙 요약 메모리 메뉴에서 별도로 확인.

## 한계 및 위험

- 크랙이 공식적으로 제공하는 **일괄 수정 API**가 아니라 개별 메시지 편집 엔드포인트를 반복하는 유저스크립트임.
- 오래된 메시지를 수정할 때의 분기·상태·요약 부수효과는 확인되지 않음. 메시지 ID/순서를 검사하지만 모든 부수효과를 검출하지는 못함.
- 서버에 이미 제출된 수정은 중단 버튼으로 되돌리지 못할 수 있음. 원본 백업 파일 보관.
- **요약 메모리는 서버 대화 메시지와 별도**여서 변경 후에도 이전 이름이 AI에게 전달될 수 있음. 공식 안내에서는 장기 기억의 직접 편집만 지원하며 그 외 요약 항목은 제약이 있음.
- 기존에 생성된 AI 답변을 재생성하거나 과거 프롬프트를 소급 변경하지 않음.
- 개인 대화 및 로그인 토큰을 GitHub에 업로드하지 않음.
- iPhone Safari/Stay 실제 로그인 세션에서 PATCH 성공 여부는 **아직 검증되지 않음**.

## 코드 검증

JavaScript 문법 검사 및 모의 API에서 대화 2건 수정·반복 실행 시 중복 건너뛰기·전체 ID 검사 통과. 실제 사용 전에는 백업과 1건 시험 수정이 필요함.
