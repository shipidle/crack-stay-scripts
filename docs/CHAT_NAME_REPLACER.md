# 🔁 채팅 이름 일괄 치환 (BETA)

[Stay 설치 링크](https://raw.githubusercontent.com/shipidle/crack-stay-scripts/beta/Crack_Chat_Name_Replacer.user.js)

## 기능

- **현재 열린 채팅방만** 대상. 다른 채팅방은 각각 별도 설정.
- 찾을 문자열의 기본값은 **시류**, 바꿀 문자열의 기본값은 **유우**.
- **현재 방 화면에서 치환**: 화면에 로드된 대화의 글자만 변경. 과거 대화로 스크롤해 새로 불러오는 메시지도 표시 시 변경. 설정은 Stay 스크립트 로컬 저장소에 방별 보관.
- **전체 기록 검색**: 저장된 대화를 크랙의 읽기 API로 마지막 페이지까지 조회하고 전체 메시지 수, 일치 메시지 수, 발견 횟수 및 미리보기 8개 표시. 임의의 최대 400페이지(약 20,000개) 제한을 초과하거나 조회가 중단되면 불완전한 결과를 전체 결과라고 표시하지 않음.
- **원본 백업 JSON**: 서버에서 읽은 해당 방 대화의 원본 보관.
- **치환본 JSON**: 원본 메시지의 content에서 찾을 글자를 바꾼 **오프라인 사본** 보관.

## 사용 순서

1. 크랙 채팅방을 열고 화면 오른쪽 아래의 **🔁** 버튼을 선택.
2. 찾을 이름과 바꿀 이름 확인: **시류 → 유우**.
3. **전체 기록 검색**을 실행하고 완료 메시지와 일치 횟수 확인.
4. 안전을 위해 **원본 백업 JSON**부터 저장.
5. **현재 방 화면에서 치환** 체크 후 **설정 적용**. 원상복구하려면 체크 해제.
6. 필요한 경우 **치환본 JSON**도 저장.

## 중요한 한계

**이 스크립트는 서버에 저장된 채팅 메시지의 원문을 수정하지 않음.** 크랙의 읽기 API만 사용하며, 서버 쓰기 API는 확인되지 않아 안전하지 않은 요청을 추측해서 보내지 않음.

- 화면에서 **유우**로 보여도 크랙 서버에는 **시류**로 저장되어 있을 수 있음.
- **AI에게 전달되는 이전 대화 문맥이나 요약 메모리**는 바뀌지 않음. 그 부분의 실제 변경을 원한다면 크랙이 지원하는 공식 수정 기능 및 요약 메모리 항목을 별도로 다뤄야 함.
- 다른 브라우저·기기나 스크립트 미설치 환경에서 동일하게 보인다고 보장하지 않음.
- 내보내기한 JSON을 크랙에 일괄 가져오는 기능은 제공하지 않음.
- iPhone Safari에서는 다운로드 진행 여부를 파일 앱이나 Safari 다운로드 목록에서 확인.
- 현재 페이지가 제공하는 메시지 DOM 속성 또는 API 응답이 변경되면 일부 표시/조회가 작동하지 않을 수 있음.

## 검증 범위

- JavaScript 문법 검사 통과.
- 실제 로그인된 크랙 페이지 및 iOS Stay에서의 통합 실행, 서버 원문 수정 기능은 검증하지 않음.
