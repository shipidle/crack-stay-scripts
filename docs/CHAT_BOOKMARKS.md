# 🔖 채팅 찾기·북마크

현재 `beta` 채널 전용. [Stay 설치/덮어쓰기](https://raw.githubusercontent.com/shipidle/crack-stay-scripts/beta/Crack_Chat_Bookmarks.user.js)

## 사용법

1. 채팅 입력창 도구줄에서 **🔖**를 누르면 팝업이 열림. 대사 번역기와 같은 28px 원형 버튼.
2. 채팅 본문에서 남길 문장을 드래그하거나 길게 선택 → **🔖 북마크** → 코멘트 입력 → **저장**.
3. **북마크** 탭에서는 저장한 문장과 코멘트를 함께 검색. **코멘트 수정**으로 메모를 변경할 수 있음.
4. **전체 대화** 탭은 이 방의 과거 대화까지 페이지를 끝까지 불러와 검색. 북마크 여부와 관계없이 검색됨. 검색 결과의 **원문 펼치기**에서 문장을 선택해 북마크하거나, **대화 전체 북마크** 사용 가능.
5. 북마크의 **원문 보기**는 팝업 안에 해당 대화 전문을 표시함. 가상 스크롤 위치를 강제로 이동하지 않음.
6. 상단 **체크박스**를 켜면 각 북마크 왼쪽에 체크박스가 나타남. 검색 결과 전체 선택·선택 삭제·이 방 전체 삭제 지원. 전체 삭제는 검색어와 무관하게 현재 방의 모든 북마크·코멘트에 적용되며 확인창이 표시됨.
7. **⚙**에서 영문 대소문자 구분·문장 선택 버튼 표시를 설정. **×**로 닫기.

## 저장과 정렬

- `GM_getValue` / `GM_setValue`로 설치된 스크립트의 기기 내 저장소에 저장. 서버 업로드·AI 호출·기기 간 동기화 없음.
- `/stories/.../episodes/{id}`, `/characters/.../chats/{id}`, `/u/.../c/{id}`의 채팅방 ID로 분리.
- **원문 대화의 최신순**으로 정렬. 옛 문장을 나중에 북마크해도 맨 위로 올라오지 않음. 같은 메시지 안에서는 뒤쪽 문장이 먼저 표시됨.
- 첫 저장 시 대화 API의 순서를 확인. 처음부터 끝까지 불러온 후 저장하므로 긴 방에서는 시간이 걸릴 수 있음. 이후 같은 페이지에서는 불러온 원문을 재사용.
- 전체 대화는 메모리에만 유지하고 북마크 문장·코멘트·원문 ID·순서만 영구 보관. 방 전환·새로고침 시 대화 원문 캐시는 비워짐.
- 새 대화·수정 내용은 전체 대화 탭의 **↻**로 갱신. 수집 중에는 **중단** 가능. 중단·API 오류 시 일부만 검색 가능하다는 상태가 표시됨.
- 원문을 삭제해도 이미 저장한 문장·코멘트는 유지됨. 원문이 없는 북마크는 마지막으로 확인한 순서를 유지.
- 같은 문장이 여러 대화에 있어 원문을 확정할 수 없으면 임의로 연결하지 않음. 전체 대화에서 해당 원문을 펼쳐 다시 선택하면 됨.
- 스크립트 삭제·기기 저장소 삭제 시 데이터가 없어질 수 있음.

```sh
node scripts/test-chat-bookmarks.mjs
# jsdom이 설치된 환경에서 저장·검색·방 전환·삭제 통합 검증
node scripts/test-chat-bookmarks.mjs --dom
# Playwright 및 브라우저가 설치된 환경에서 실제 DOM 동작 검증

```

브라우저 검증은 기존 스크립트에서 확인한 DOM·API 형식을 재현한 fixture를 사용함. 실제 크랙 로그인 세션이나 iOS Stay 확장 내부 실행을 대체하지 않음.
