# Vercel 모델 직접 입력

대상: 캐챗 어시스턴트 2.41.0, 개인 요약 AI 2.2.0, 대사 번역기 0.5.0 이상.

1. [설치센터](../INSTALL.md)에서 사용 중인 main 또는 beta 스크립트를 덮어쓴 뒤 크랙 새로고침.
2. [Vercel AI Gateway](https://vercel.com/ai-gateway)에서 API 키 발급.
3. 각 스크립트 설정의 **API 제공자/방식 → Vercel AI Gateway** 선택.
4. **Vercel AI Gateway 키** 입력.
5. [모델 목록](https://vercel.com/ai-gateway/models)에서 모델 ID를 복사해서 입력하고 저장.

Gemini 3.8 Flash 모델 ID:

    google/gemini-3.8-flash

Vercel에 웹사이트를 배포하거나 환경변수를 등록할 필요 없음. 각 스크립트에서 Gateway를 직접 호출함. 표시 이름 대신 제공자/모델명 ID를 입력해야 함.

## 어디에 입력하는지

- **캐챗 어시스턴트:** 톱니바퀴에서 제공자·키 저장 → 질문 화면의 모델 입력란에 ID 입력. 기본 Vercel 모델은 Gemini 3.8 Flash임.
- **요약 AI:** 설정의 **20턴 요약 · Vercel 모델 ID**와 **51→10 재요약 · Vercel 모델 ID**를 각각 입력. 재요약 모델을 비우면 20턴 요약 모델을 사용함.
- **대사 번역기:** 패널에서 제공자·키·모델 ID를 입력하고 설정 저장. 번역 언어 선택은 기존대로 유지됨.

기존 설치는 Google/Firebase 제공자·키·모델을 보존함. Vercel로 쓰려면 제공자를 직접 바꾸면 됨. Google 키를 Vercel 키 칸에 넣으면 안 됨. 키와 모델은 이 기기의 스크립트 설정이며 Lore Sync의 방별 번역 노트에 포함되지 않음.

## 동작과 비용

- 캐챗 어시스턴트는 현재 대화 맥락에 대한 정보형 답변을 제공함.
- 요약 AI의 20턴 주기, 기존 2~3개 생성 규칙, 51→10 재요약·검증·백업·중복 방지 방식은 유지됨. 두 작업의 모델만 분리됨.
- 번역기는 입력창의 따옴표 안 한국어 대사만 교체함. 지문과 기존 언어별 지정 기능은 유지됨.
- 임의 모델의 비용을 다른 모델 단가로 계산하지 않음. Vercel 실제 비용은 Vercel 대시보드에서 확인. 기존에 계산된 누적 비용에는 Vercel 사용분이 포함되지 않음.
- 요약·번역 모델은 JSON 구조화 출력을 지원해야 함. 지원하지 않는 모델·잘린 응답·잘못된 키는 오류로 표시하며 불완전한 응답을 저장하지 않음.

연결·응답 처리는 모의 API로 검사함. 실제 Vercel 키를 통한 유료 호출 및 iPhone/Stay 실사용은 별도 확인 필요.
